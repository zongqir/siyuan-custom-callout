# SiYuan Custom Callout

[中文版](./README_zh_CN.md)

A clean and elegant SiYuan plugin that renders ordinary blockquotes as beautiful Callout blocks.

<!-- Support moved to bottom -->

> **⚠️ Important**: This plugin **does NOT modify your note content**. It only renders styles by parsing blockquote titles. All content is preserved and can be reverted to regular blockquotes anytime.

---

## 💡 Core Features 

- 🧭 **Callout Outline Dock** - A dedicated dock panel to list and navigate callouts in the current document
- ⌨️ **Text-driven Command** - Type `[!type] Title` then Enter; the plugin parses and formats a native callout instantly
- 🎨 **Custom Types & Themes** - More subtypes/colors on top of native presets, styled to match your theme

- 🧰 **Customizable Quick Menu Panel** - Build your own quick menu of common callout types for one-tap insertion

## 🧩 Tips

- Type `>` + `space` to create a blockquote, then type to filter the callout menu
- Or type `[!type] Title` then `Enter`; the plugin parses text and formats natively

---

## ✅ Compatibility & Data Safety

- 100% native-friendly: works on native blockquotes + `data-subtype`, no custom HTML injection
- Zero data mutation: never rewrites your notes; content remains valid without the plugin
- No lock-in: install/uninstall has no impact on your data or workflows
- Theme-safe: degrades gracefully and follows your theme styles
