# SiYuan Custom Callout

[中文版](./README_zh_CN.md)

A clean and elegant SiYuan plugin that renders ordinary blockquotes as beautiful Callout blocks.

> **⚠️ Important**: This plugin **does NOT modify your note content**. It only renders styles by parsing blockquote titles. All content is preserved and can be reverted to regular blockquotes anytime.

---

## ✅ Requirements

- SiYuan >= 3.5.0
- Plugin >= 3.0.0 (this document)

## 💡 Core Features

- 🧭 **Sidebar Outline** - Quickly scan key callouts in the current document
- 🔁 **Native Fold/Unfold** - Top-right transparent toggle, persisted via native APIs
- 🎯 **Preset + Custom Callouts** - Use built-ins or your own `data-subtype`

## 🧩 Tips

- Type `>` + `space` to create a blockquote, then type to filter the callout menu
- Or type `[!type] Title` then `Enter`; the plugin parses text and formats natively
