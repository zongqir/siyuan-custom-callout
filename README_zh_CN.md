# 思源自定义引述块 (SiYuan Custom Callout)

[English](./README.md)

一个简洁优雅的思源笔记插件，将普通引述块渲染为美观的 Callout 提示块。

<!-- 支持模块移至文末 -->

> **⚠️ 重要说明**：本插件**不会修改你的笔记内容**，仅根据引述块文本解析并渲染样式。所有内容原封不动，随时可恢复为普通callout。

## ⌨️ 小贴士

- `>` + 空格创建引述块，出现菜单后直接输入字母/中文筛选并回车
- 也可输入 `[!type] 标题` 后回车，插件立即解析并格式化为原生 Callout

---

## 💡 核心能力

- 🧭 **Callout 大纲面板（Dock）**：列出并导航当前文档的 Callout
- ⌨️ **文本驱动命令**：输入 `[!type] 标题` + 回车，立即解析为原生 Callout
- 🎨 **自定义类型与主题**：在原生预设基础上扩展更多子类型/颜色，样式贴合主题
- 📝 **自定义快捷菜单**：将常用 Callout 类型加入个人快捷菜单，一键插入
- 🎴 **快速闪卡功能**：一键将任意 Callout 转换为闪卡，支持间隔重复学习

---

## ✅ 兼容性与数据安全

- 100% 兼容原生：仅处理原生引述块与 `data-subtype`，不注入自定义 HTML
- 零数据改写：不修改你的笔记内容；卸载插件后内容仍保持有效
- 无锁定：安装/卸载对数据与工作流没有任何影响
- 主题友好：样式遵循系统主题，降级平滑
