# 思源自定义引述块 (SiYuan Custom Callout)

[English](./README.md)

一个简洁优雅的思源笔记插件，将普通引述块渲染为美观的 Callout 提示块。

> **⚠️ 重要说明**：本插件**不会修改你的笔记内容**，仅通过解析引述块标题来渲染样式。所有内容完全保留，可随时恢复为普通引述块。

---

## ✅ 使用要求

- 思源版本：>= 3.5.0
- 插件版本：>= 3.0.0（本文档）

## 🚀 3.0 新变化

- 原生折叠/展开（右上角透明按钮），状态持久化
- 侧边栏 Callout 大纲优化，主题兼容性更好
- UI 细节统一与对齐修正

## 📖 快速开始（30 秒）

1. 在集市搜索并安装本插件
2. 文档中输入 `[!类型] 标题` 后回车（或用 `>` 触发菜单选择类型）
3. 右上角按钮可折叠/展开；侧边栏会自动抓取并展示关键信息

---

## ⌨️ 小贴士

- `>` + 空格创建引述块，出现菜单后直接输入字母/中文筛选并回车

---

## 💡 核心特性

- 🧭 **侧边栏大纲**：自动抓取文档中的 Callout 关键信息
- 🔁 **原生折叠**：右上角按钮，一键折叠/展开并持久化
- 🎨 **预设 + 自定义**：内置多种类型，也支持自定义子类型
- 🧩 **原生 data-subtype**：与系统一致，主题兼容友好
- 🔒 **非侵入式**：不改动内容，仅渲染样式
